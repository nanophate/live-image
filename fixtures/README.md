# Regression fixtures

The two images in `source/` are original, AI-generated regression fixtures made
for this repository on 2026-07-19 with OpenAI's built-in image generation tool.
They do not depict or intentionally imitate an existing character or franchise.

They deliberately vary hair colour, eye colour, line treatment, and shading,
while remaining inside the first supported input envelope: one near-frontal,
unoccluded, head-and-shoulders anime character with both eyes open.

| File | Fixture description |
| --- | --- |
| `teal-librarian.png` | Crisp cel shading, teal bob, amber irises |
| `copper-courier.png` | Softer shading, wavy copper hair, cyan irises |
| `unsupported-no-face.png` | Locally generated colour gradient; expected detector rejection |

Generated artifacts belong in `compiled/` and detector overlays in `overlays/`.
The generated artifacts are ignored because they are reproducible from the
source images and compiler.

`browser/*.rig.json` contains the compiler-authored metadata and embedded
protected-line masks for the two primary fixtures, but deliberately omits the
large source-image `dataUrl`. The Playwright test combines each rig with its
already-tracked `source/*.png` at test time. These snapshots were generated by
Compiler 0.3.0 with the model hashes recorded inside each file; they exercise
real automatic-detection offsets without committing duplicate image payloads.

## Prompt record

Both prompts required one original adult character, a centred near-frontal
head-and-shoulders composition, two unobstructed open eyes with visible pupils,
a visible closed mouth, a plain background, and no text, watermark, logo,
signature, or existing intellectual property. The two subjects were an amber-
eyed fantasy librarian and a blue-green-eyed sky courier.

`unsupported-no-face.png` is a deterministic gradient created locally with
ImageMagick. It exists to prove that the compiler does not fabricate a rig when
the dedicated detector returns no face.
